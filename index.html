The 13 classes

Each week, one production layer goes on the service.

You build the same ML service all cohort long, adding one production layer per class. Thursdays, 2 hours live. Here's what each week covers.

Sep 10 · Git + Linux/Shell Toolkit

Branches, rebase, PR hygiene — plus the shell commands that buy 80% of the leverage.

Sep 17 · Production Python

uv, FastAPI skeleton, pytest. Code shape that survives review, not notebook patterns.

Sep 24 · REST APIs & Model Serving

The real model goes in. Loading, versioning, contract design, failure modes.

Oct 1 · Docker for ML

Multi-stage builds, layer-cache discipline, GHCR. ML images shouldn't be 4 GB.

Oct 8 · Kubernetes, Just Enough

Pods, Deployments, Services, HPA. The mental model — not the certification.

Oct 15 · CI/CD for ML

GitHub Actions. PR runs tests, main builds and pushes. OIDC over PATs.

Oct 22 · Monitoring for ML

Prometheus, Grafana, RED metrics — and the drift signals traditional APM misses.

Oct 29 · Logs & Observability

Structured logs, correlation IDs, OTel tracing. One ID threaded end-to-end.

Nov 5 · SQL & Databases

Postgres, indexes, EXPLAIN, transactions, connection pooling.

Nov 12 · ML Pipelines

Airflow DAG that retrains weekly. MLflow tracking. Idempotency patterns.

Nov 19 · AWS + IaC

Terraform for ECR + EKS + RDS. IAM the way it's actually written. Cost levers.

Dec 3 · Capstone + The Junior Role

Trace one request through every layer. Capstone PR opens. What the role really looks like.

Dec 10 · LLM Serving + Demo Day

vLLM, batching, cost economics — then the cohort presents their capstones. Graduation.

No class Nov 26 (Thanksgiving). Recordings posted within 24 hours if you miss a week.
